# Mini-Avito

REST API сервис для управления объявлениями (аналог упрощённой версии Avito). Реализован на Go с использованием чистой архитектуры, PostgreSQL и Docker.

## 🚀 Основные возможности

- **Создание объявления** — валидация заголовка (3–100 символов), цены и категории
- **Получение объявления** — по ID с проверкой существования
- **Список объявлений** — пагинация на основе курсора (keyset pagination), фильтрация по категории
- **Обновление объявления** — частичное обновление полей (PATCH)
- **Удаление объявления** — мягкое удаление из БД

## Особенности реализации  
Пагинация (Keyset Pagination)  
Используется подход с курсором (id < cursor), который эффективнее OFFSET на больших объёмах данных:  

Стабильная производительность даже на больших таблицах  

Отсутствие дублирования записей при переходе между страницами  

Транзакционность  
Все операции записи (создание/обновление) выполняются в транзакциях PostgreSQL для гарантии целостности данных.  

Кастомные ошибки  
Реализована своя иерархия ошибок:  

ErrInvalidInput — некорректный ввод  
ErrAlradyExists — уже создано  
ErrAdNotFound — сущность не найдена  
ErrAdInvalidPrice — некорректная цена  
ErrInvalidTitle — некорретное название  
ErrInvalidCategory — некорректная категория  

Позволяет гибко обрабатывать ошибки в HTTP-слое  

Индексы  
- idx_ads_category — для быстрой фильтрации по категории  
- idx_ads_created_at — для сортировки по дате
